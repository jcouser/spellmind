# Security

## Reporting a problem

Please report security problems privately, through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/jcouser/spellmind/security/advisories/new). Don't open a public issue.

Include what you found, how to reproduce it, and which version (the app's window shows it; in game, Settings shows the addon's). You'll get an answer within a week.

## What counts

- Anything that could leak an API key, a sign-in or personal data.
- A way for another program, another Windows account or a web page to make the app do something.
- A way for game text, a web page or an AI answer to make the addon or app run code or act without you.
- A tampered or unexpected download from this project's releases.

## Downloads

Only download Spellmind from [this repository's releases](https://github.com/jcouser/spellmind/releases) or its CurseForge page. Each release lists the installer's SHA-256; [docs/install.md](docs/install.md) shows how to check it.
